# 分词与歧义消解（从 0 实现）

起始环境只有本说明、`samples/**` 与 `.gitignore`，没有实现代码。交付引擎（`wordcut/` 包：库 + `python -m wordcut` 入口，Python 3.13 标准库）、`web/` 下的切分结果页面、`tests/`（`unittest`）；页面是原生 HTML/ES module，无构建、无依赖。

## 一、范围

要做：读入一份或多份词典与一份 UTF-8 正文，输出带偏移的分词序列；覆盖长词优先、正反两种候选的裁决与兜底、未登录段、空白与标点、英文与数字混排；同一输入跑两遍结果一致。

不做：不做词性标注、命名实体识别、新词发现、繁简转换、全半角归一化、拼音与纠错；不联网、不引入随机数；不做索引与检索服务、词典热加载、增量更新；不引入第三方库、打包器与构建步骤。切分结果与时钟无关，只有页面上的耗时是运行读数。

## 二、口径与公式

### 2.1 匹配

- 词典匹配大小写敏感、全半角敏感，不做 Unicode 归一化；空白不参与匹配。
- 某位置有多个匹配词时取字符数最多者（长词优先），没有匹配就是未登录。
- 词典词不含空白，匹配不会跨空白。

### 2.2 分段

正文先按空白切成若干「段」（连续非空白字符即一段），段内独立裁决、互不影响，偏移仍按整篇算；空白本身不产生 token。

### 2.3 两种候选

- 正向最大匹配 FMM：段内从左到右，每步取以当前位置为起点的最长匹配词。
- 反向最大匹配 RMM：段内从右到左，每步取以当前位置为终点的最长匹配词。
- 两者都不做全局最优搜索、不做回溯；未登录处按 2.5 切。

### 2.4 裁决与兜底

把一段的候选切分记成 `K = (词数 n, 单字词数 s, 词频和 F)`：

1. `n` 小者胜；
2. `n` 相同比 `s`，`s` 小者胜；
3. `s` 也相同比 `F`，`F` 大者胜；
4. 三项全同取 FMM（兜底）。

等价写法：按 `(n, s, -F)` 字典序取最小，相等时取 FMM。`F` 是各 token 词频之和（未登录 token 记 1），`s` 数长度为 1 的 token（含标点与单字）。

### 2.5 未登录段

- 段内当前位置没有匹配时：ASCII 字母（`A`–`Z`、`a`–`z`）连续串算 1 个 token，ASCII 数字（`0`–`9`）连续串算 1 个 token，其余字符每字符 1 个 token。
- 未登录串不吞词典词：正向延伸遇到「该位置存在词典匹配」即停，反向延伸遇到「该位置是词典词的结束位置」即停。
- 全角字母数字（`Ａ`、`１`）不算字母数字，按其余字符逐字切；标点、生僻字同样逐字。

## 三、状态机与数据结构

- 词条 `(词, 词频)`：词频是 1..10^9 的十进制整数，缺省 1；多份词典合并成一张词表，同一词条取最大词频。
- 切分项 `(start, end, 词面)`：`start`/`end` 是码位下标，半开区间。
- 一段的派生量 `n`、`s`、`F` 见 2.4；段内先各自产出 FMM 与 RMM 两串候选，再按 2.4 取其一。
- 状态：`方向（正/反）`、`当前位置`、`已产出的切分项`；正向走到段尾、反向回到段首即结束，最后按整篇顺序拼接。

## 四、输入输出与文件格式

一律 UTF-8 无 BOM、LF；末行也要有换行。

### 4.1 词典 `samples/dicts/*.tsv`

一行一条：`词` 或 `词<TAB>词频`。空行与 `#` 开头的整行跳过；词内不得含空白与制表符；字段多于两个、词频不是 1..10^9 的十进制整数都按输入不可用处理。同一词条重复出现取最大词频，不算错，结果与文件顺序无关。

### 4.2 正文 `samples/text/*.txt`

不预清洗：空格、制表、换行、标点、英文、数字原样参与处理，`\r\n` 不折叠；非法 UTF-8 按输入不可用处理。

### 4.3 命令行（仓库根目录）

```
python -m wordcut cut  --dict samples/dicts/basic.tsv --input samples/text/tiny.txt --output var/tiny.tsv
python -m wordcut page --dict samples/dicts/basic.tsv --input samples/text/tiny.txt --output web/index.html
```

`--dict` 可给多次，按命令行顺序合并；退出码 0 成功、1 输入不可用、2 用法错误，非 0 不写输出文件。

### 4.4 输出 `samples/expected/*.tsv`

每行 `起始偏移<TAB>结束偏移<TAB>词面`，无表头、无空行、无注释。偏移是码位下标（0 起、半开区间），不是字节偏移；按 `start` 严格递增、token 互不重叠，除空白外覆盖正文全部字符；词面等于正文该区间的原文，不做任何转换。空正文输出空文件。

### 4.5 切分结果页面

`page` 写一个自包含 HTML 到 `web/`（验收用 `web/index.html`）：数据内联在 `<script type="application/json" id="segment-data">`，含 `input`、`dicts`、`words`（合并后词条数）、`elapsed_ms`（含词典加载的切分耗时，整数毫秒）、`text`、`tokens`（`[起, 止, 词面, 类型]`）与 `stats`（`chars`、`tokens`、`singles` 长度 1 的切分项数、`unknown` 词面不在合并词表里的切分项数）。

类型由引擎给出，取值四个：`dict` 词典词、`latin` 未登录 ASCII 字母串、`digit` 未登录 ASCII 数字串、`other` 其余（单个汉字、标点、全角字符）。`<script type="module">` 只渲染不重算，不引外部资源、不 `fetch`，双击即开：`id="text"` 原样渲染正文（空白保留），每个切分项包成带 `data-start`/`data-end` 的 `<span>`，按类型标色并配图例，悬停显示起止偏移；`id="stats"` 显示 `words` 与 `elapsed_ms`；`id="tokens"` 列出偏移、词面与类型。

## 五、性能与验收口径

预算（本机、单进程、含词典加载）：最大词典 `large-300k.tsv` 30 万条，正文单份上限约 2 MB；30 万条词典 + 2 MB 正文的 `cut` ≤ 8 s，峰值常驻内存 ≤ 512 MB。不得对每个位置线性扫整本词典。

1. 五组样例（见第六节）各跑一遍，输出与同名期望文件逐字节相同（含行尾换行）。
2. 偏移逐条核对：按 `start`/`end` 切片必须等于词面；所有词面按顺序拼接必须等于正文去掉空白后的内容。
3. 确定性：`cut` 的输出重复运行逐字节一致，不依赖哈希随机化、locale、环境变量与网络；页面里的 `elapsed_ms` 是运行读数，不参与比对。
4. 不硬编码：不得把样例结果或样例词表写进代码，也不得对样例特判；评测会换词典与正文。
5. 页面：用 `text/tiny.txt` 生成 `web/index.html`，类型标色、悬停显示起止、词典规模与耗时四项齐全，文件不引用外部资源。
6. `tests/`（`unittest`）覆盖四条裁决与未登录口径、全绿；全空白正文输出空文件、同一份词典给两次结果不变。

## 六、样例说明

| 词典 | 正文 | 期望结果 | 覆盖点 |
| --- | --- | --- | --- |
| `dicts/basic.tsv` | `text/tiny.txt` | `expected/tiny.tsv` | 长词优先、单字词、标点、英文与数字 |
| `dicts/ambiguous.tsv` | `text/rules.txt` | `expected/rules.tsv` | 逐行覆盖 2.3–2.4 的裁决 |
| `dicts/basic.tsv` + `dicts/ambiguous.tsv` | `text/mixed.txt` | `expected/mixed.tsv` | 未登录字母与数字、全角、生僻字、空白 |
| `dicts/large-300k.tsv` + `dicts/basic.tsv` | `text/corpus-news.txt` | `expected/corpus-news.tsv` | 30 万词条、1.4 MB 正文 |
| `dicts/large-300k.tsv` + `dicts/ambiguous.tsv` | `text/corpus-forum.txt` | `expected/corpus-forum.tsv` | 多词典合并、1.1 MB 正文 |

`rules.txt` 一行一段，行号即用例号：1–2 行两种方向结果相同，长词优先直接生效；3 行按词数取反向；4 行按单字词取反向；5 行按词频和取反向；6 行三项全同取正向兜底；7 行先取重复词条的最大词频、再按词频和取正向。`notes.md` 是现场记录，只作背景，不作为口径。
